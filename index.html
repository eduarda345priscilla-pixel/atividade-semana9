Sobre

A Sneaker Store é um projeto acadêmico criado para apresentar um catálogo virtual de tênis de diferentes marcas e categorias.

O site utiliza HTML, CSS, Bootstrap e JavaScript, com dados organizados em uma estrutura JSON.

O objetivo é permitir que o usuário visualize os produtos e acesse suas informações detalhadas de maneira simples e responsiva.
